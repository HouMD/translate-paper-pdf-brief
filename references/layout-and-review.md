# 排版与检查规则

## 页面与文字

- 默认 A4 纵向单栏，约 20 mm 页边距、1.5 倍正文行距，可按实际阅读效果调整；页码重新编排，不强求原分页。
- 正文宋体五号 10.5 pt；摘要、关键词、图表翻译、脚注等用楷体五号。
- 新排版内容的西文字体默认使用 Times New Roman（新罗马），包括英文标题、作者姓名、西文引文、参考文献、字母、阿拉伯数字及西文单位。中西文混排时按文字片段选择字体，不因所在段落使用楷体或宋体而让西文继承中文字体。按需使用 Times New Roman 的斜体、粗体及粗斜体，保留数学变量的样式与上下标。字号遵循所在内容的层级。原始图表及公式截图内的文字保持原样，不为统一字体而重绘。
- 原文明显小于正文的内容默认楷体六号 7.5 pt；可读性优先，过小时增大至五号或合适字号。
- 英文标题、中文标题及所有层级的标题、小标题必须加粗，包括摘要、各级章节、附录、致谢和参考文献标题；可按层级调整字号。西文使用 Times New Roman 粗体，中文保留宋体并采用描边加粗，不静默改为其他字体。章节及小标题使用独立的 `heading` 内容块；加粗范围不扩展至正文、摘要内容或图表说明，也不修改原始截图内的标题。原文斜体强调对应中文可用楷体，数学变量保留原样式和含义。
- 第一页顶部依次放英文标题、中文标题、原作者姓名、期刊、发表日期、年份卷期、页码或文章号、DOI 等实际可获得的出版信息；不虚构缺失信息，不将接收日期误当发表日期。随后接摘要，不默认使用独立封面。
- 嵌入所用的中文和西文字体，正文可搜索复制；检查范围包括标题、作者、出版信息、版权符号、正文、图注及参考文献。参考文献条目完整保留英文与原顺序，可重新排版。

## 图表与公式

裁剪框以 PDF 点记录（72 pt = 1 inch）。先按原分辨率无损截取并保存图像；创建新 PDF 时，图表及其原英文注释可在源裁剪框尺寸的 80%–120% 范围内等比缩放。优先采用 A4 纵向单栏和约 20 mm 页边距，通过 80%–120% 的尺寸调整及版面安排减少大段空白，同时保证图表与图注清晰可读、适合打印。不得非等比拉伸；超过此范围仍放不下时，才使用单独页面或更大页面。

图表放在与原文相同的段落之间，按原顺序插入，正文为图表让位。空间不足顺延至下一页，必要时用单独横向或更大页面。优先保证图表清晰，其次全文可读性。原图模糊时记录限制，不声称截图能恢复细节。

图表正下方附完整中文图注/表注，并提供图内坐标轴、图例、标记等的“英文 → 中文”对应说明。表格翻译表头、文字单元格和脚注，标明行列对应关系；数值不重复抄写，不默认重建完整中文表格。可使用其他空白区域，但关联必须清晰，不覆盖正文或图表。

中文图注结束后，“图中说明：……”必须另起一行或另起一段，不与前面的图注连续排在同一行；将“图内说明”等同义标签统一为“图中说明”。表格的“表内文字对应：……”也另起一行。此换行属于输出排版要求，必须在生成的 PDF 中实际生效，不能只依赖 Markdown 源码的普通换行。

尽量让图表与中文说明同页；说明太长可续页，标“图 X 说明（续）”或“表 X 说明（续）”。多面板图保留结构和标签。公式保留编号和上下文位置，清晰裁剪，避免遗漏行内变量和上下标。

## 保留的中间材料

每篇论文采用以下目录结构，顶层保持简洁：

```text
TRANSLATE/中英_<原文献名>/
  <原文文件名>.pdf
  中文翻译_<原文献名>.pdf
  tmp/
    translation.md
    translation_blocks.json
    source_blocks.json
    terminology-and-sources.md
    prepare.py
    paper.json
    crop_manifest.json
    pdf_work_v1/
    crops/
    source_pages/
    review_pages/
    drafts/
    ...
```

示例名称可按实际需要调整，不创建无用的占位文件。原文块和译文块一一对应，记录 ID、原页码、类型和顺序。图表清单记录源页、裁剪框、dpi、宽高点数及插入位置。术语记录包含英文、译文、语境、词典冲突和查证 URL。上述材料及所有代码和临时产物统一保存在 tmp 内，排版脚本使用明确的论文根目录与 tmp 路径，将完成的交付 PDF 输出到论文根目录；不得自动清理中间文件。

通用生成与检查代码随skill保存在`scripts/`，论文内默认只保存配置、数据、报告和必要的专属提取／适配脚本。模块接口、字体配置、缓存及交付检查见 [模块配置与调用](portable-module.md)。不要把既往论文的固定文件名、13页、32条参考文献、符号正则或图表坐标复制为新论文默认值。

## 验收

1. 逐源页核对章节、段落、脚注、图表、公式编号和参考文献，确认无遗漏、重复或双栏串行。
2. 复核数值、单位、正负号、范围、显著性、否定、因果与相关区别、限定条件及术语一致性。
3. 检查裁剪边界，无图例、注释或面板标签被切掉。输出图表保持源裁剪框宽高的 80%–120%，宽高按相同比例变化；检查图表及中英文图注可读、页面适合 A4 打印。
4. 渲染最终 PDF 的全部页面并逐页查看缺字、遮挡、越界、意外空白、过小字号、标题孤行及图注关联；确认中英文主标题和所有层级的小标题均实际加粗，且中文笔画清晰、不粘连。裁剪图还应单独放大检查；缩略图不足以判断细字质量。
5. 确认 PDF 正常打开，正文可搜索复制；西文采用 Times New Roman，“图中说明”实际另起一行；论文顶层仅保留原文和交付 PDF，其余产物全部进入 tmp。修复后重新检查受影响页面和分页变化区域。保留检查记录与未解决原文疑点。
6. 运行模块的`delivery`，要求`ready:true`。该结果绑定当前PDF及输入文件，并验证每页存在有效目检记录；只有实际看过页面后才能调用`review`登记。脚本失败返回非零状态，不能因为PDF文件已生成就交付。

真实试译与用户反馈是效果验收的一部分；结构校验不能证明翻译质量。
